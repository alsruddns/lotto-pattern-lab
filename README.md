# Lotto Pattern Lab

한국 로또 6/45의 과거 회차를 대상으로 순서 없는 6개 번호 집합의 규칙을 탐색하는 연구 도구입니다. 이 엔진은 당첨을 예측하거나 보장하지 않으며, 분석 결과는 무작위 대조군과 독립 테스트 구간에 비춰 평가해야 합니다.

## 설치

Python 3.11 이상이 필요합니다. 기존 `.venv`를 활성화하거나 아래처럼 직접 실행합니다.

```powershell
.\.venv\Scripts\python.exe -m pip install -e .
```

## 데이터 입력

CSV는 UTF-8 형식이며 `round,n1,n2,n3,n4,n5,n6` 열이 필요합니다. 보너스 번호는 선택 열 `bonus`로 넣을 수 있습니다. 회차는 숫자가 작을수록 과거이며, 번호는 1~45에서 중복 없이 6개여야 합니다.

```csv
round,n1,n2,n3,n4,n5,n6,bonus
1,10,23,29,33,37,40,16
2,9,13,21,25,32,42,2
```

저장소에는 공식 출처로 검증된 실데이터가 포함되어 있지 않습니다. CSV는 `csv_unverified`로 기록되며 출처 URL은 참고용으로 저장할 뿐 자동 인증하지 않습니다. 출처를 확인한 데이터를 사용할 책임은 업로더에게 있습니다. CSV가 없으면 아래 합성 무작위 데이터 경로로 엔진을 실행할 수 있습니다.

## GP 탐색 실행

작은 설정으로 합성 데이터에서 실제 탐색과 대조군 실행을 확인합니다.

```powershell
lotto-pattern-lab search --synthetic 180 --population 40 --generations 10 --workers 4 --controls 3 --seed 12345
```

CSV를 사용하려면 다음처럼 실행합니다.

```powershell
lotto-pattern-lab search --csv .\data\draws.csv --source-url "https://공식-출처-주소" --population 80 --generations 25 --workers 4 --controls 3 --seed 12345
```

개체군 크기, 세대 수, 교차/돌연변이 확률, 최대 깊이, 난수 시드, CPU 워커(1~4), 학습/검증 비율 및 대조 반복 수를 설정할 수 있습니다. 매 세대 진행과 현재 후보를 출력하며 JSON 진행 스냅샷과 최종 결과를 `experiments/`에 저장합니다.

### Streamlit 연구 화면

```powershell
python -m streamlit run src/lotto_pattern_lab/app.py
```

화면에서 CSV 또는 합성 데이터, 탐색 파라미터, 진행 상황, 후보 공식, 기존 실험 비교 및 JSON 다운로드를 사용할 수 있습니다.

## 탐색 및 평가 방식

- 한 수식은 회차 번호와 이전 최대 10회차의 집합 요약량을 받아 1~45의 후보 번호 하나를 출력합니다. 적합도는 해당 회차의 순서 없는 실제 6개 번호 집합에 후보가 포함된 비율입니다. 단일 번호 무작위 기준은 `6/45`입니다.
- 입력 요약량은 번호 합, 제곱합, 쌍곱합, 소수 997에 대한 곱의 나머지, 최솟값·최댓값 및 직전 회차 간 합 차이입니다. 정렬 위치를 추첨 순서로 해석하지 않습니다.
- DEAP 연산자는 덧셈, 뺄셈, 곱셈, 안전 나눗셈, 안전 나머지, 절댓값, 최소, 최대, 제곱, 세제곱입니다. 수식 깊이는 설정값으로 제한되고 노드 수는 35개 이하입니다.
- 데이터 예시를 시간순으로 학습/검증/독립 테스트 구간에 나눕니다. GP 적합도는 학습 구간에서 계산하고, 검증 적합도와 복잡도 페널티로 후보를 고릅니다. 독립 테스트 구간은 선택 이후에만 점수를 계산합니다. 테스트 중 다음 회차의 입력에는 그 시점까지 공개된 과거 회차만 사용합니다.
- 실제 데이터와 길이가 같은 독립 무작위 6/45 데이터마다 같은 GP 탐색 및 검증 선택을 실행합니다. 여러 대조 탐색의 테스트 최고값과 경험적 p 값을 보고해 탐색 과정의 선택 편향을 살펴봅니다. 대조 횟수가 적으면 p 값 해상도도 낮습니다.

## PySR 연동 준비 상태

회차 데이터, 순서 불변 특징, 시간순 분할, GP 실행, 공통 평가 지표와 JSON 실험 기록을 분리해 두어 PySR를 별도 탐색 백엔드로 추가할 수 있습니다. PySR 패키지와 백엔드는 아직 설치하거나 구현하지 않았습니다. 이후에는 같은 특징·분할·대조군으로 GP와 PySR 후보를 비교하도록 연결할 수 있습니다.
